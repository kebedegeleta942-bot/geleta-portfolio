## Run Locally

Requires Node.js 20.19+ or 22+.

```bash
# Clone the repository
git clone https://github.com/kebedegeleta942-bot/geleta-portfolio.git

# Navigate into the project
cd geleta-portfolio

# Install dependencies
npm install

# Start the development server
npm run dev

# Run TypeScript checks
npm run typecheck

# Create production build
npm run build

# Preview production build
npm run preview
```

The development server normally runs at `http://localhost:5173`.

## Contact Form

The contact form validates visitor input and supports the following behavior:

1. Sends form data to a configured endpoint, if available.
2. Otherwise, opens the visitor's email application when an email address is configured.
3. Displays a message when contact functionality is not configured.
